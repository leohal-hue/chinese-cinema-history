一条资料，怎样逐步可靠？

当前资料来自三份影片信息 Excel。当前版本已获项目维护者确认，后续发现的疑点单独写入补充备注；逐条文献核对进度继续保留。书目、版本与页码仍可补全。

逐步补充依据

  1. 核实来源的作者、书名、出版版本，并补充资料页码。原表行号用于追踪导入位置，不能代替文献页码。
  2. 核对片名、别名、年份含义及前后集或续作的条目边界。保留原文，不只凭同名合并影片。
  3. 逐项核对人物身份、姓名、职务和公司名称。同字姓名暂归为候选，尚未完成身份与机构沿革考证。
  4. 演员与角色先从原文人工拆分，不按空格批量断开姓名。
  5. 信息相互冲突时保留不同说法的来源，标为“有争议”。补充备注里的格式疑点不等于已认定的史实错误。

提交纠错与补充

在条目中点击“在 GitHub 提交纠错”，填写建议内容及文献依据，维护者审核后更新。也可以下载纠错模板，填写后交给维护者；下载本身不会提交或修改资料。

进入独立 GitHub 仓库。普通读者可通过议题（Issue）补充线索，协作者可修改 data/ 中的 CSV 并通过修改请求（Pull Request）提交。条目编号固定保留，合入后的资料更新会生成网页。

阅读关系图时

边上的职务来自原表。“编导／导演”保留原列含义，尚未细分。同片参与关系不等于私人交往或公司雇佣关系；缺少关系边也不代表不存在联系。

资料下载包含当前条目、候选名称、关系、核对任务和来源线索。网站与数据的再利用许可仍待维护者选定。
